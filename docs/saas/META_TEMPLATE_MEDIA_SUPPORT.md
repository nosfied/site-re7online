# Meta Template Media Support

Status: P2 / PRODUCT + META CAPABILITY.

Last updated: 2026-09-16.

## Scope

Future hardening must audit and implement professional support for WhatsApp
Marketing templates with media where product/contract scope requires it.

Required capability areas:

- category `MARKETING`;
- IMAGE header;
- VIDEO header;
- Meta media/example requirements;
- upload and media handle lifecycle;
- template preview;
- variables;
- buttons where supported by Meta for the template type;
- submission;
- approval/rejection status;
- rejection reason;
- send using an approved template;
- current official Meta Marketing pricing source.

## Current CRA Classification

Marketing media templates are not part of the current CRA Utility controlled
campaign front.

Do not mix this work with:

- approved outbound return destination delivery;
- recipient B controlled Utility validation;
- opt-out E2E;
- reports / exports / billing closure.

If CRA Contract/TR evidence explicitly requires Marketing media template
capability for current acceptance, stop for owner decision and potentially
promote this item from P2 to a CRA contract front.

Until then, the current CRA campaign front remains Utility-first and
Marketing-media work stays parallel P2.
