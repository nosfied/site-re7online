# Executive Deck Converta

Material em Markdown estruturado para posterior conversao em PowerPoint, Google Slides ou PDF institucional.

Arquivo principal:

- `converta-executive-deck.md`

Orientacao:

- Cada bloco `---` representa um slide.
- Os bullets foram escritos para apresentacao executiva.
- As notas do apresentador podem ser usadas como roteiro comercial.
- Antes de usar em proposta oficial, ajustar nome do cliente, escopo, volumes, SLA e infraestrutura ofertada.
