# Minuta - Declaracao De Uso De API Oficial Meta

DEA TECNOMARKETING LTDA, pessoa juridica de direito privado, declara para fins de participacao no Pregao Eletronico 90004/2026 do Conselho Regional de Administracao do Parana - CRA-PR que a solucao Converta Platform opera com canais digitais Meta por meio de APIs oficiais e configuracoes compatíveis com as politicas da Meta/WhatsApp Business Platform.

## Declaracoes

1. A solucao utiliza API Oficial do WhatsApp Business / Meta Cloud API para operacao do canal WhatsApp, conforme configuracao tecnica aplicavel ao tenant/contrato.

2. A solucao pode operar canais digitais Meta, incluindo WhatsApp, Facebook Messenger e Instagram Direct, conforme permissoes, configuracoes, disponibilidade de APIs e validacoes aplicaveis.

3. A solucao nao utiliza WhatsApp Web como mecanismo principal de integracao.

4. A solucao nao utiliza extensoes de navegador, robos nao homologados, scraping ou mecanismos nao oficiais como base para envio/recebimento de mensagens WhatsApp.

5. A operacao observa as politicas da Meta, incluindo regras de templates, janela de atendimento, categorias de mensagens, qualidade da conta e limites de envio.

6. A empresa prestara apoio tecnico para ativacao, configuracao, templates, acompanhamento de qualidade da conta e operacao dos canais digitais previstos no contrato.

7. Prazos, aprovacoes, bloqueios, limites e categorias definidos pela Meta dependem da propria Meta e serao acompanhados tecnicamente pela contratada, com comunicacao ao contratante.
