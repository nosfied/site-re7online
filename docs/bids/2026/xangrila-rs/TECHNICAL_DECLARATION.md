# Xangri-La/RS PE 115/2026 - Declaracao Tecnica Base

Documento-base para declaracao tecnica. A versao final deve ser revisada juridicamente, colocada em papel timbrado e assinada fora do Git.

## Declaracao

A licitante declara, para fins de participacao no Pregao Eletronico 115/2026 de Xangri-La/RS, que a solucao ofertada, Converta Platform, possui arquitetura SaaS web, multi-tenant, destinada a gestao de mensagens e atendimento digital via WhatsApp Cloud API oficial.

## WhatsApp Oficial

A solucao utiliza API Oficial WhatsApp Business/Cloud API da Meta para envio e recebimento de mensagens.

A solucao nao utiliza WhatsApp Web, QR persistente, emulacao de aparelho ou API nao oficial como requisito principal para operacao contratual.

## LGPD E Seguranca

A plataforma contempla controles de seguranca e privacidade, incluindo:

- segregacao por tenant;
- controle de acesso por usuario/perfil;
- trafego via HTTPS/TLS em ambiente produtivo;
- logs operacionais com redacao de segredos quando aplicavel;
- politicas de retencao;
- backup operacional;
- restricao de acesso a dados conforme permissao.

## Suporte E Manutencao

A licitante se compromete a prestar suporte, manutencao corretiva, preventiva e atualizacoes durante a vigencia contratual, conforme prazos, canais, severidades e condicoes estabelecidos na proposta final e no contrato.

## Integracao

A solucao possui recursos de integracao por API, webhooks, importacao e exportacao. Integracoes especificas dependem de credenciais, documentacao tecnica, disponibilidade do sistema externo e homologacao pelo contratante.

## Treinamento

A licitante se compromete a executar treinamento presencial em 3 turmas de 5 pessoas e reciclagem mensal remota, conforme plano de implantacao aprovado.

## Observacao

Esta declaracao deve ser usada apenas apos revisao juridica e confirmacao de que o edital nao exige modelo proprio.
